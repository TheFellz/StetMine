# StetMine Website

Статический сайт StetMine, подготовленный для GitHub Pages.

## Публикация через GitHub с телефона или компьютера

1. Скачай ZIP и распакуй его.
2. Открой свой GitHub-репозиторий.
3. Нажми **Add file → Upload files**.
4. Загрузи содержимое папки `stetmine-github` в корень репозитория (файл `index.html` должен лежать прямо в корне).
5. Нажми **Commit changes**.
6. Открой **Settings → Pages**.
7. В разделе Build and deployment выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохрани.
8. Подожди завершения публикации.

## Что есть

- Анимированное интро с логотипом S.
- Адаптивная главная страница.
- Разделы: игрокам, сборка, новости, скины, поддержка.
- Формы регистрации (никнейм, email, пароль, подтверждение пароля) и входа.
- Личный кабинет и демонстрационная админ-панель.
- PWA manifest и базовый service worker.

## Важно: текущие ограничения

Это **полностью готовый статический фронтенд**, но не полноценная серверная система.
Регистрация и вход сейчас демонстрационные: данные сохраняются в `localStorage` конкретного браузера. Они не синхронизируются между устройствами, не защищены сервером и не подходят для настоящих аккаунтов. Админ-панель также локальная и не имеет реальной авторизации.

Для публичной эксплуатации необходимо подключить backend API и PostgreSQL:
- безопасное хеширование паролей (Argon2id);
- серверные сессии / refresh tokens;
- роли и права доступа;
- модерацию заявок и лимит регистраций;
- серверную отправку обращений;
- реальные новости, скины, загрузки и статус игрового сервера.

Не размещай реальные пароли и не используй демо-админку как настоящую панель управления.

## Конфигурация

Сайт не требует сборки и установки зависимостей. Открой `index.html` локально или опубликуй на GitHub Pages.
